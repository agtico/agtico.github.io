The Intelligence Reports channel is now live as the publication layer for AGTI.

Reports are stored as dated Markdown files, rendered by Jekyll, and published through GitHub Pages with stable URLs. This keeps the system lightweight while making every report easier to index, share, archive, and extend.

## Publication Model

Each report lives in `_posts` with front matter for the title, date, summary, category, and tags. The reports index, RSS feed, sitemap, and individual report pages all read from that same source.

## Operating Scope

This channel is reserved for market intelligence, model notes, Task Node updates, Post Fiat Network research, and other AGTI operating dispatches.
