What The Business Is

Palo Alto Networks is a large enterprise cybersecurity vendor in the Technology / Software Infrastructure category. It sells security platforms across network security, cloud security, security operations, AI security and identity; the company says it serves 70,000+ customers and is powered by Unit 42 threat intelligence. ([paloaltonetworks.gcs-web.com](https://paloaltonetworks.gcs-web.com/news-releases/news-release-details/palo-alto-networks-reports-fiscal-third-quarter-2026-financial)) Its current strategy is “platformization”: consolidating customers from multiple point-security products onto broader PANW platforms, which management says improves retention and expansion.

What It Does

PANW’s portfolio includes next-generation firewalls, SASE, software firewalls, Cortex/XSIAM for security operations, Prisma AIRS for AI security, cloud security, and—after the CyberArk deal—identity security. In the June 2, 2026 earnings-call excerpt, management emphasized that AI workloads are increasing machine-to-machine traffic, identity exposure, and attack speed, which PANW argues raises demand for inline inspection, automated SOC response, and agent/identity governance. Recent acquisitions extend this stack: Koi is intended to add “agentic endpoint” security to Prisma AIRS and Cortex XDR, while Portkey adds an AI gateway control plane for monitoring, orchestrating, and governing autonomous agents at scale.
